# Korean-MESSENGER
A Sentence Dataset for Korean Text Entry Evaluations

## 필수 사항
해당 데이터셋을 연구에 이용하기 위해선 **아래의 3가지**를 당부드립니다.
1. [국립국어원 언어정보나눔터](https://kli.korean.go.kr/corpus/main/requestMain.do?lang=ko)를 인용해주시기 바랍니다.
2. [국립국어원 언어정보나눔터](https://kli.korean.go.kr/corpus/main/requestMain.do?lang=ko)에 가입 후, '온라인 대화 말뭉치 2021'과 '메신저 말뭉치'를 사용 신청하여 주시기 바랍니다.
3. 이후 연구 목적에 따라 [본 논문](https://www.dbpia.co.kr/Journal/articleDetail?nodeId=NODE12131607)을 인용해주시기 바랍니다.
